## Things I've built

### cALorie

Upload a workout video and get exercise segments, repetition counts, timed holds and an estimated calorie range.

I built it because I wanted to see how far pose landmarks and relatively simple movement rules could go without pretending every frame could be classified perfectly.

[Live app](https://c-a-lorie.vercel.app) · [Source](https://github.com/bariscelikk1/cALorie) · [How it works](https://github.com/bariscelikk1/cALorie/blob/main/docs/how-calorie-works.md)

### DermAI

A seven-class skin-lesion image classification experiment built with EfficientNetB0 and the HAM10000 dataset.

Most of the work was not just training the model—it was dealing with class imbalance, preventing data leakage and building a training pipeline that behaved consistently. This is a research prototype, not a diagnostic tool.

[Demo](https://dermai-steel.vercel.app) · [Source](https://github.com/bariscelikk1/dermai)

### Mihenk

An early-stage open-source project for evidence-based talent matching and team optimization.

We're exploring how portfolio evidence, statistical scoring and constrained optimization can produce more transparent matches between institutions and young talent.

[Project repository](https://github.com/bariscelikk1/mihenk)
